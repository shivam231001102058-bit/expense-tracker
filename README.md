# Pocketwise Expense Tracker

A responsive React single-page application for tracking income and expenses. It uses Vite for development, Recharts for dashboard analytics, and localStorage for persistence.

## Getting started

```sh
npm install
npm run dev
```

## Available checks

```sh
npm run build
npm run lint
npm test
```

The app supports adding and deleting transactions, monthly summaries, category filtering, localStorage persistence, and CSV export. The analytics dashboard includes expense totals by category, monthly income-versus-expense comparisons, and daily expense trends.
